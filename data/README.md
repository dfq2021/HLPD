# HLPD data

All files are JSON objects with two aligned lists — `original` (human-written) and
`rewritten` / `sampled` (machine-revised or machine-generated) — following the ImBD
convention `{dataset}_{task}_{source-model}.raw_data.json`. Every benchmark file holds
150 pairs unless stated otherwise. Human sources: **XSum** (news), **SQuAD** (QA context),
**WritingPrompts** (stories), **PubMedQA** (biomedical QA) and **WikiText** (encyclopedic).

```
data/
├── raw/                         human-written source passages (150 per dataset)
├── train/                       HLPO training data
├── prompts/                     prompt pools used to build the benchmarks
├── single_task/                 ImBD-style single-task benchmark (polish / rewrite / expand / generation)
├── adversarial_multitask/       ★ adversarial multi-task revision benchmark (Sec. 3.1, Table 3)
├── advanced_generation/         ★ text fully generated by advanced LLMs (Table 2)
├── multilingual/                Chinese / Portuguese / Spanish (Fig. 8)
├── iterative_revision/          1–5 successive machine revisions (Table 8)
└── truncation/                  30–180-word truncations for length robustness (Fig. 9 / 10)
```

## Training data (`train/`)

| file | pairs | description |
|---|---:|---|
| `train_multitask_revision.raw_data.json` | 3,354 | **HLPD training set.** The human passages of the ImBD training pool, each revised under one randomly chosen revision task (polish / rewrite / expand / generate). Used for HLPO with `x_h ≻ x_m`. Keys: `original`, `sampled`. |
| `imbd_polish_500.raw_data.json` | 500 | ImBD polish training set (GPT-3.5-turbo), for the ImBD / ImBD‡⋆ baselines. |
| `imbd_polish_3000.raw_data.json` | 3,354 | ImBD polish training pool. |

## Adversarial multi-task revision benchmark (`adversarial_multitask/`)

Human passages from XSum / WritingPrompts / SQuAD / WikiText revised by four advanced LLMs
under prompts drawn from the five-dimensional adversarial prompt pool (`prompts/adversarial_prompts.json`,
200 unique DeepSeek-R1-written prompts combining *revision goal × style × "sound human" request ×
constraint × auxiliary request*, Appendix B.3).

| source model | API version | files |
|---|---|---|
| `gpt-4o` | gpt-4o-2024-05-13 | `{xsum,writing,squad,wiki}_adversarial_gpt-4o.raw_data.json` |
| `claude-3.5-sonnet` | claude-3-5-sonnet-20241022 | … |
| `deepseek-r1` | deepseek-r1 (thinking) | … |
| `gemini-2.5-pro` | gemini-2.5-pro-exp-03-25 | … |

## Advanced-LLM generation (`advanced_generation/`)

XSum prefixes (first 30 words) continued into ~150-word articles by `claude-3.5-sonnet`,
`deepseek-r1`, `gemini-2.5-pro` and `grok-3` (Appendix B.1).

## Single-task benchmark (`single_task/`)

The ImBD protocol (rewrite / polish / expand / generation) with six source models
(`gpt-3.5-turbo`, `gpt-4o`, `Qwen2-7B`, `Llama-3-8B`, `Mistral-7B`, `Deepseek-7b`) plus extra
rewrite sets from `claude-3-5-sonnet`, `gemini-1.5-flash`, `gemini-2.0-flash-exp` and `grok-2-1212`.
`rewrite` and `polish` cover all five datasets; `expand` / `generation` use XSum
(`gpt-3.5-turbo` expand also covers Writing / SQuAD / PubMed).

## Multilingual (`multilingual/`)

`{Chinese,Portuguese,Spanish}_train_500_rewrite_gpt-3.5-turbo` (500 pairs, training) and
`{…}_test_150_rewrite_gpt-3.5-turbo` (150 pairs, evaluation).

## Iterative revision (`iterative_revision/`)

`{dataset}_iter{k}_{model}.raw_data.json`: the machine text after `k` successive revisions
(`gpt-4o`: XSum / Writing; `gemini-2.0-flash-exp`: XSum / Writing / SQuAD / Wiki;
`gpt-4o-mini`: PubMed / SQuAD / Wiki + Writing iter 1). A few files contain 147–149 pairs.

## Truncation (`truncation/`)

Both passages of a pair truncated to 30 / 60 / 90 / 120 / 150 / 180 words:
`polish/{gpt-3.5-turbo,gpt-4o,deepseek-r1}` and
`adversarial_multitask/{claude-3.5-sonnet,deepseek-r1,gemini-2.5-pro}` (XSum).
`speed/xsum_polish_gpt-3.5-turbo_10` holds the 10 passages used for timing.

## Prompts (`prompts/`)

| file | count | used by |
|---|---:|---|
| `adversarial_prompts.json` | 200 | `tools/build_revision_data.py --task adversarial` |
| `polish_prompts_imbd.json` | 150 | ImBD polish protocol (`tools/data_builder.py`) |
| `expand_prompts_imbd.json` | 150 | ImBD expand protocol |

Regenerate a larger pool with `tools/adversarial_prompt_generator.py` (the paper uses 750 prompts).

## Rebuilding

* API models: `scripts/build_adversarial_data.sh` (`tools/adversarial_prompt_generator.py`,
  `tools/build_revision_data.py`, `tools/build_generation_data.py`; set `HLPD_API_BASE` / `HLPD_API_KEY`).
* Open-source models: `scripts/build_data_opensource.sh` (`tools/data_builder.py`).
* Truncations: `tools/truncation.py -i <file> -o data/truncation/<...>`.

The cached T5-3B perturbation files of the DetectGPT / NPR baselines
(`*.t5-3b.perturbation_100.raw_data.json`, tens of MB each) are not shipped; they are
recreated automatically by `scripts/eval_other_models.sh`.
